`mend`: one command-line tool that applies the edits AI models write, in four formats (unified diffs with
wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON edit calls), to a tree of text files. It finds
the lines an edit names at the first of three matching tiers and writes every change or none.

## Run it

```sh
node main.ts change.diff
```
